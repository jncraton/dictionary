# BST Dictionary

Implement a Dictionary Abstract Data Type (ADT) using a Binary Search Tree (BST).

## Learning Outcomes

After completing this experience, learners will be able to:

1. Implement a Binary Search Tree (BST).
2. Map a Dictionary ADT to a BST structure.
3. Manage key-value pairs in C++.

## Usage

Once compiled, you can run your program as:

```
./bst_dict
```

Output includes a number of tests to ensure the program works correctly followed by a number of extremely useful dictionary statistics.

## Testing

The code includes a number of embedded tests that can be run using:

```
make test
```

## Tasks

1. Implement the `Node` struct and `BST` class.
2. Implement the `BSTDict` class.
3. Complete the `get`, `insert`, and `clear` methods.
